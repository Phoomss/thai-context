## 2. Data Governance & Ethics Policy

1. **การเคารพแหล่งที่มาและลิขสิทธิ์:** แสดงการให้เกียรติและระบุข้อมูลของสำนักงานราชบัณฑิตยสภาและศูนย์ศึกษาภาษาถิ่นอย่างชัดเจนในทุกหน้าจอ
2. **ความโปร่งใสเรื่องข้อมูลจาก AI:**
   - ข้อมูลที่เป็นนิยามดั้งเดิมจะติดป้าย `Official Dictionary Source`
   - ข้อมูลสรุป บริบท หรือการเชื่อมโยงที่เกิดจาก LLM จะติดป้าย `AI-Inferred / AI-Assisted`
3. **การรักษาความคงสภาพทางประวัติศาสตร์ (Data Immutability):** ห้ามลบหรือเขียนทับข้อมูลของปี 2542 และ 2554 โดยเด็ดขาด เพื่อคงคุณค่าทางภาษาศาสตร์ไว้เปรียบเทียบ

## 3. Risks & Mitigations

| ความเสี่ยง (Risk) | โอกาส / ผลกระทบ | แผนการจัดการและลดความเสี่ยง (Mitigation) |
| :--- | :---: | :--- |
| **ความคลาดเคลื่อนของรูปวรรณยุกต์/สระในการพิมพ์** | ปานกลาง / สูง | มีฟิลด์ `headword_clean` และใช้ GIN Trigram Index เพื่อให้ค้นหาเจอแม้ผู้ใช้พิมพ์สระตกหล่นหรือพิมพ์ผิดเล็กน้อย |
| **AI เกิดอาการ Hallucination ในคำศัพท์เฉพาะทาง** | ต่ำ / สูง | มี Guardrail ตรวจสอบค่าความมั่นใจจาก Retrieval หากต่ำกว่าเกณฑ์จะตัดเข้าสู่ Safe Abstention Response ทันที |
| **การเชื่อมโยงภาษาถิ่นอาจเกิดข้อถกเถียงเชิงวัฒนธรรม** | ปานกลาง / ปานกลาง | แยกสถานะ `OFFICIAL_DATA` ออกจาก `AI_INFERRED` อย่างเด็ดขาด และเปิดให้ผู้ใช้กดส่งข้อคิดเห็นผ่านช่องทาง Feedback |
| **Latency จากการประมวลผล Vector + LLM** | ปานกลาง / ปานกลาง | ใช้ Streaming Text Generation (SSE) สำหรับคำตอบของ AI และแคชคำค้นหายอดนิยมในฝั่ง Backend |
